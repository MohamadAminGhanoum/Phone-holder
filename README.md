# Phone-holder
I want to make a phone holder that i can put on my table, and make it like a night stand, so that when im sleeping, i can look at my phones always on displaya.
It is possible to see the 3d view, i have uploaded it into printables: https://www.printables.com/model/1552444-phone-holder/files

I decided on making this project, since i have the ikea phone holder, but i cant use it for my phone, since my phonecase makes my phone thick which makes it impossible to fit in it. So i decided to make a phone holder i can put on my table.
